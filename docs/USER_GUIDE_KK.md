# VikhmanSSH — Функционалдың егжей-тегжейлі сипаттамасы және пайдаланушы нұсқаулығы

## 1. Жалпы шолу

VikhmanSSH — SSH арқылы қашықтағы серверлерді басқаруға арналған жұмыс үстелі қолданбасы. Бұл жүйелік әкімшілер, әзірлеушілер және DevOps мамандары үшін Linux немесе Unix ұқсас машинаға жылдам әрі қауіпсіз түрде қосылуға, қашықтағы терминалда жұмыс істеуге, қашықтағы файлдарды қарап шығуға, жүктеп салуға/түсіруге, мәтіндік құжаттарды өңдеуге және қолданба ішінде медиа мазмұнын көруге арналған құрал.

Жоба PySide6 және Paramiko негізінде жасалған Qt-қа негізделген қолданба болып табылады. Ол бірнеше бір уақытта SSH сессияларын қолдайды, бірнеше тілде интерфейсті ұсынады, қауіпсіз host key тексеруді, сондай-ақ алдын ала қарап шығу және редактор бар қашықтағы файл менеджерін қамтиды.

Бағдарламаның негізгі идеясы пайдаланушыны бір ортада ұстап, төмендегілерді жасау болып табылады:

- бірнеше қашықтағы хосттарға қосылу,
- белсенді терминалдар арасында ауысу,
- қашықтағы шелде interactieve командалар орындау,
- қашықтағы файлдарды қарап шығу және өзгерту,
- каталогтар мен файлдарды басқару,
- журналдар мен қателерді қарау,
- бірнеше тілдегі интерфейсті пайдалану.

## 2. Негізгі функционалдық мүмкіндіктер

### 2.1 Көптеген серверлерді басқару

Бағдарлама бір уақытта бірнеше қашықтағы қосылымды сақтай алады. Әр сервер серверлер тізімінде өз жеке элементі ретінде көрсетіледі. Тізімде қосылым күйі мен күй көрсеткіштері болуы мүмкін, сондықтан пайдаланушы қай хосттар онлайн, офлайн, ажыратылған немесе ағымдағы белсенді екендігін тез түсіне алады.

Негізгі жұмыс тәртібі:

1. сервер профилін қосу,
2. қосылым параметрлерін енгізу,
3. аутентификация режимін таңдау,
4. сессияны ашу,
5. терминал немесе файл менеджерінде жұмыс істеу.

Пайдаланушы staging, testing, production, ішкі инфрақұрылым немесе жеке әзірлеу машиналары сияқты әртүрлі ортаға арналған бірнеше профильдер жасай алады.

### 2.2 Қашықтағы терминал

Әр сервердің жеке терминал сессиясы бар. Терминал PTY негізінде жұмыс істейді және төмендегілерді қолдайды:

- пернетақта енгізулерін тікелей беру,
- ANSI түсті нәтиже,
- терминал өлшемін өзгерту,
- тышқан оқиғалары,
- мәтінді таңдауға және көшіру/қоюға қолдау,
- бір уақытта бірнеше белсенді сессия.

Бұл шел тәжірибесін нақты SSH терминал эмуляторы сияқты жасайды. Бағдарлама терминалдың үстінде SSH аутентификация кезеңдері мен қосылым қателерін көрсететін журнал панелін де көрсетеді. Бұл қашықтағы аутентификация, SSH конфигурациясы, host key немесе sudo рұқсаты мәселелерін анықтауға көмектеседі.

### 2.3 Автоматты host key сенімділігі және тексеру

Белгісіз хостқа алғаш қосылған кезде бағдарлама SSH host key қабылдап, оны жергілікті қолданба деректер каталогында сақтайды. Бұл пайдаланушыны үзілістерден сақтайды және бірінші рет қосылу кезінде қосымша өздігінен конфигурация жасамайды.

Келесі қосылым әрекеттерінде бағдарлама сақталған host key мен нақты сервер key арасындағы сәйкестікті тексереді. Егер сәйкессіздік болса, қосылым қабылданбайды. Бұл TOFU (Trust On First Use — алғаш пайдалану кезінде сенім) моделі: бірінші key сенімді болып саналады, ал кейінгі сәйкессіздіктер күдікті болып қабылданады.

Host key fingerprint қосылым журналында көрсетіледі, сондықтан пайдаланушы оны сенімді, тәуелсіз арна арқылы жоғары деңгейлі жүйелер үшін тексере алады.

### 2.4 Сервер профилінің сақталуы және аутентификация режимдері

Бағдарлама сервер профилдерін операциялық жүйенің қолданба деректер каталогында сақтайды. Бұл хост, порт, пайдаланушы аты, сондай-ақ SSH қайталау жолы немесе аутентификация әдісін қамтиды. Бағдарлама серверлік профиль файлында құпия сөздерді немесе passphrase-тарды сақтамайды.

Қолдау көрсетілетін аутентификация түрлері:

- пароль негізіндегі SSH аутентификация,
- SSH агенті арқылы аутентификация,
- private key файл жолымен аутентификация,
- қажетті жағдайларда интерактивті аутентификация.

Құпия сөздер қарапайым мәтіндік файлдарда емес, OS keyring жүйесінде сақталады. Бұл конфигурация файлдары арқылы кездейсоқ ақпараттың ағуға кіруінің алдын алады.

### 2.5 Қашықтағы файлдар үшін файл менеджері

Файл менеджері SFTP арқылы жұмыс істейді және пайдаланушыға:

- қашықтағы каталогтарды қарауға,
- папкаларды шарлауға,
- жергілікті файлдарды серверге жүктеп салуға,
- серверден файлдарды компьютерге түсіріп алуға,
- каталогтар жасауға,
- элементтерді атауын өзгертуге немесе жоюға,
- метадеректер мен каталогтарды қарауға

мүмкіндік береді.

Бұл әсіресе конфигурация файлдарын, журналдарды, скрипттерді, деплоймент артефакттарын немесе жобалық каталогтарды көшіру үшін пайдалы.

### 2.6 Файлдарды алдын ала қарау және көру

Бағдарлама бірнеше файл түрлеріне арналған кіріктірілген қарау құралын қамтиды. Қолдау көрсетілетін санаттарға мыналар жатады:

- суреттер,
- PDF,
- аудио файлдар,
- видео файлдар.

Басқа файл түрлері жүйелік қолданба немесе әдепкі сыртқы өңдегіш арқылы ашылады.

Алдын ала қарау режимі қашықтағы файлдың уақытша көшірмесін жүктейді, максималды өлшем шектеуі бар. Бұл жобада шек 512 МБ. Бұл толық файлды пайдаланушының локальді жұмыс кеңістігіне тұрақты түрде көшірусіз үлкен құжаттар мен медиа файлдарды көруге мүмкіндік береді.

### 2.7 Синтаксис ерекшелендіргішті бар қашықтағы мәтіндік редактор

Бағдарлама қашықтағы хосттағы мәтіндік файлдарды тікелей өңдеуді қолдайды. Бұл конфигурация файлдарын, шел скрипттерін, YAML, JSON, Python, JavaScript және басқа ұқсас файлдарды өзгерту үшін пайдалы.

Негізгі мүмкіндіктер:

- қашықтағы файлды екі рет шерткенде ашу,
- файл кеңейтіміне негізделген синтаксис ерекшелендіру,
- Ctrl+S арқылы сақтау,
- 2 МБ-қа дейін UTF-8 мәтіндік файлдар,
- сақтау алдында қайшылықты тексеру.

Файлды сақтағанға дейін бағдарлама файлды ашқаннан бері серверде өзгерген жоқ па, бар-жоғын тексереді. Бұл басқа пайдаланушының өзгертулерін немесе редактор ашық кезде файлды басқа процесс өзгерткенін перезаписпен жоғалтудан сақтайды.

### 2.8 Root / sudo режимі

Файл менеджерінде Root / sudo параметрі бар. Қосылған кезде ол қажет болған кезде SFTP серверін sudo арқылы іске қосады. Бұл қашықтағы машинада жоғары құқықтармен жұмыс істеуге мүмкіндік береді.

Поведение:

- егер sudo пароль сұрамайтын болса, режим dərіде іске қосылады,
- пароль қажет болса, бағдарлама sudo паролін сұрайды,
- пароль жергілікті түрде сақталмайды,
- қашықта sudo конфигурациясы және `sftp-server` исполняемая файлы дұрыс орнатылуы керек.

Бұл мүмкіндік әкімшілерге қорғалған жүйелік каталогтардағы файлдарды оқу, өңдеу немесе жылжыту үшін пайдалы.

### 2.9 Интерфейс тілдері және көптілділік

Бағдарлама бірнеше интерфейс тілін қолдайды. Баптаулардан тілді өзгертуге болады. Қолдау көрсетілетін тілдер:

- араб,
- қытай,
- ағылшын,
- француз,
- қазақ,
- орыс,
- испан.

Интерфейс тілі баптауларда сақталады. Тілді өзгерткеннен кейін бағдарлама қайта іске қосылады, сондықтан жаңа.locale барлық модульдерге біркелкі қолданылады.

Аударма файлдары жобаның `locales/` каталогында орналасқан. Әр JSON файлында түпнұсқа орыс интерфейс жолдарының картасы және мақсатты тілге аудару бар.

### 2.10 Деректер және конфигурацияны сақтау

Бағдарлама пайдаланушы деректерін операциялық жүйеге тән конфигурация каталогында сақтайды:

- Windows: `%APPDATA%\ServerManager`
- macOS: `~/Library/Application Support/ServerManager`
- Linux: `${XDG_CONFIG_HOME:-~/.config}/server-manager`

Сол каталогта әдетте мыналар сақталады:

- `servers.json` — сервер профилдері,
- `settings.json` — интерфейс және бағдарлама баптаулары,
- `known_hosts` — сенімді SSH host key-тері,
- OS қолдаған жағдайда құпия сөздерді сақтау үшін keyring деректері.

Бұл орналасу бағдарламаға портативтілікті береді, бірақ бір уақытта ОС-тің күтпеген орналасу ережелеріне сәйкес келеді.

## 3. Бастау

### 3.1 Міндетті талаптар

Проектті бастапқы кодтан іске қосу үшін:

- Python 3.9 немесе одан жаңа,
- Linux жүйесінде графикалық жұмыс сессиясы,
- `requirements.txt` ішіндегі тәуелділіктер,
- қосылғыңыз келетін серверлерге SSH қолжетімділігі қажет.

### 3.2 Қолмен орнату

Жоба түбірінде:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

### 3.3 Іске қосу сценарийлері

Репозиторийде іске қосу мен жинақтау сценарийлері бар:

- Linux/macOS: `./run.sh`
- Windows: `run.bat`

Сценарийлер қажет болған жағдайда виртуалды ортаны жасайды және қажетті тәуелділіктерді орнатады. Бұл алғашқы конфигурацияны жеңілдетеді және бағдарламаның дұрыс Python ортасында жұмыс істейтінін қамтамасыз етеді.

### 3.4 Дербес жинақ

Дербес, тарқатылатын пакет жасау үшін:

- Linux/macOS: `./build.sh`
- Windows: `build.bat`

Қолданылатын дербес пакеті көп жағдайда `dist/VikhmanSSH` каталогында пайда болады (macOS жүйесінде `.app` бумасы). Бұл бағдарламаны Python немесе тәуелділіктерсіз пайдаланушыға тарату үшін пайдалы.

> Маңызды: әр мақсатты платформаның жинағын сол платформада құрыңыз. PyInstaller операциялық жүйелер арасында кросс-компиляцияны қолдамайды.

## 4. Типтік пайдаланушы жұмыс циклі

### 4.1 Сервер профилін жасау

Негізгі қолданбада жаңа сервер профилін қосуға болады:

- қосылым атауы,
- хост немесе IP адрес,
- SSH порты,
- пайдаланушы аты,
- SSH ключ жолы немесе пароль әдісі,
- қосымша параметрлер.

Профиль кейінірек қайта пайдалану үшін жергілікті түрде сақталады.

### 4.2 Қосылым ашу

Сервер профилі жасалғаннан кейін пайдаланушы қосыла алады. Қосылым кезінде бағдарлама SSH handshaking-ін жүргізеді, host key тексереді және журналда аутентификация кезеңдерін көрсетеді.

Егер сервер key жаң болса, ол қабылданып, жергілікті host key қоймасында сақталады. Егер key бұрыннан белгілі болса, бірақ өзгеріп кеткен болса, бағдарлама қосылымды қабылдамайды.

### 4.3 Терминалда жұмыс істеу

Қосылған соң пайдаланушы қашықтағы шелді көреді. Командалар тікелей серверге жіберіледі, нәтиже терминал UI-де көрсетіледі. ANSI түстері, PTY өлшемінің өзгеруі және тышқан оқиғалары сияқты мүмкіндіктер тәжірибені жергілікті терминал эмуляторына жақын етеді.

Пайдаланушы бір уақытта бірнеше қашықтағы терминалдарды ашып, серверлер тізімінен олардың арасында ауыса алады.

### 4.4 Қашықтағы файлдармен жұмыс істеу

Қосылған сервер үшін Файлдар қойындысына өткенде пайдаланушы:

- қашықтағы каталогтарды аша алады,
- жергілікті файлдарды жүктей алады,
- файлдарды жүктеп алады,
- каталогтар жасай алады,
- файлдарды жоя немесе қайта атау жасай алады,
- жүктеп алу алдында файлдарды тексере алады,
- мәтіндік құжаттарды кіріктірілген редакторда аша алады,
- суреттерді, PDF, аудио және видео файлдарын алдын ала қарастыра алады.

### 4.5 Root / sudo режимін пайдалану

Файлдық жүйе әкімшілік рұқсат керек болған кезде Root / sudo режимін қосуға болады. Бұл жүйелік конфигурация файлдарын өңдеу немесе қорғалған каталогтардағы файлдарды жылжыту үшін пайдалы. Бұл тек пайдаланушыда нақты рұқсат және заңды әкімшілік қажеттілік болған кезде қолданылуы керек.

## 5. Қауіпсіздік ескертулері

Бағдарлама ыңғайлылық пен өнімділікке бағытталғанымен, ол жоғары құқығы бар инфрақұрылымдармен жұмыс істейді. Пайдаланушы төменде көрсетілген ережелерді есте сақтауы керек:

- серверіне сенім артпас бұрын host fingerprint тексеріңіз,
- сезімтал деректерді қарапайым мәтін конфигурация файлдарында сақтамаңыз,
- жергілікті қолданба деректер каталогтарын қорғаңыз,
- мүмкіндігінше SSH кілтін пайдаланыңыз, қарапайым парольді емес,
- әкімшілік SFTP режимін қосар алдында sudo талаптарын мұқият тексеріңіз,
- production жүйелер үшін тек сенімді, аудиттен өткен инфрақұрылымды пайдаланыңыз.

Бағдарлама минималистік қауіпсіздік философиясын ұстанады: сервер профилінде құпия сөздерді сақтамайды, қолдау болса OS keyring қолданады және кейінгі қосылымдарда host key-терін тексереді.

## 6. Ақаулықтарды жою

### Мәселе: Бағдарлама іске қосылмайды

Мүмкін себептер:

- Python тәуелділіктері орнатылмаған,
- Linux жүйесінде графикалық сессия жоқ,
- виртуалды орта жоқ немесе зақымдалған,
- локальді ОС графикалық кітапханаларды жоқ деп есептейді.

Шешім:

- `python -m pip install -r requirements.txt` арқылы тәуелділіктерді орнатыңыз,
- графикалық сессияда іске қосыңыз,
- Python нұсқасының үйлесімділігін тексеріңіз,
- қажетті ортаны автоматты түрде жасау үшін жобаның іске қосу скрипттерін пайдаланыңыз.

### Мәселе: Қосылым қабылданбайды

Мүмкін себептер:

- қате пайдаланушы аты немесе құпия сөз,
- SSH key жолы дұрыс емес,
- SSH agent конфигурациясы жоқ,
- host key сәйкессіздігі,
- қашықтағы хостта SSH қызметі жұмыс істемейді.

Шешім:

- тіркелгі деректерін тексеріңіз,
- host key fingerprint-ін тексеріңіз,
- сервер SSH әдісін конфигурациясы дұрыс екенін тексеріңіз,
- журнал панелінен SSH handshaking қателерін қараңыз.

### Мәселе: Файл командалары рұқсат қатесімен сәтсіз аяқталады

Мүмкін себептер:

- қашықтағы аккаунттың мақсатты каталогқа рұқсаты жоқ,
- sudo дұрыс конфигурацияланбаған,
- қашықтағы хостта `sftp-server` бағдарламасы орнатылмаған.

Шешім:

- рұқсат болса Root / sudo режимін қосыңыз,
- sudo рұқсаты бар екенін тексеріңіз,
- серверде `sftp-server` дұрыс орындалатын жерін тексеріңіз.

### Мәселе: Үлкен файлдар дұрыс алдын ала қаралмайды

Мүмкін себептер:

- файл өлшемі алдын ала қарау шегінен үлкен,
- файл түрі кіріктірілген қарау құралымен destekтелмейді,
- қашықтағы тасымалдау немесе рұқсаттық шектеулер алдын ала қарауды блоктайды.

Шешім:

- қажет болған жағдайда локальді файлдар жүйесіне өтіңіз немесе арнайы қарау құралын пайдаланыңыз,
- алдын ала қарау шегінен кіші файлдарды пайдаланыңыз,
- кіріктірілген қарау форматы қолдамаса, файлды жүктеп алып, басқа құралмен қараңыз.

## 7. Қолдау көрсетілетін платформалар мен орта ескертулері

Бұл құрал Windows, macOS және Linux үшін десктоп қолданба ретінде жасалған. Жобада локальді орнату мен жинақтауды жеңілдететін шел сценарийлері бар. Production үшін ұсынылатын тәсіл — бағдарламаны мақсатты ОС-те жинақтау және нәтижелі буманы сол жерде тарату.

Ол Qt және графикалық интерфейске сүйенетіндіктен, оны дисплей қатынасы бар пайдаланушы сессиясында іске қосу ұсынылады. Linux жүйесінде қолданба терезесін ашу үшін GUI сессия қажет.

## 8. Қорытынды

VikhmanSSH күнделікті қашықтағы жұмыс үстелі басқару үшін қажет негізгі мүмкіндіктерді біріктіреді:

- интерактивті SSH терминал,
- бірнеше белсенді сессия,
- файлдарды тасымалдау және басқару,
- қашықтағы файлдарды өңдеу,
- медиа алдын ала қарау,
- host key тексеру,
- көптілділік,
- қауіпсіз аутентификация интеграциясы.

Бұл оны күнделікті әкімшілік, қашықтағы жөндеу, конфигурацияларды өзгерту және жылдам серверге қосылу қажет болатын операциялық процестер үшін пайдалы етеді, бұл үшін бөлек терминал эмуляторы немесе файл тасымалдау құралы қажет болмайды.
