# VikhmanSSH

Автор: Dmitriy Vikhman

Настольное приложение для управления SSH-подключениями и работы в удалённой оболочке.

## Запуск

Запуск исходного проекта на Linux/macOS:

```bash
./run.sh
```

На Windows используйте `run.bat`. Запускатели создают виртуальное окружение при необходимости и устанавливают зависимости.

## Автономная сборка

Для сборки приложения с Python и библиотеками запустите на целевой ОС:

```bash
./build.sh
```

На Windows используйте `build.bat`. Готовая папка появится в `dist/VikhmanSSH` (на macOS — также `VikhmanSSH.app`). Её можно переносить на другую машину с той же ОС без установки Python или зависимостей. Сборка каждой платформы выполняется отдельно на Windows, macOS или Linux; PyInstaller не кросс-компилирует между ОС.

## Язык интерфейса

Откройте «Настройки» в главном окне и выберите казахский или один из шести официальных языков ООН: арабский, английский, испанский, китайский, русский или французский. После сохранения программа перезапустится, чтобы перевести все открываемые модули. Выбор и данные хранятся в пользовательском каталоге приложения: `%APPDATA%\ServerManager` на Windows, `~/Library/Application Support/ServerManager` на macOS, `${XDG_CONFIG_HOME:-~/.config}/server-manager` на Linux.

Чтобы добавить язык, создайте JSON-файл в `locales/` по образцу `en.json`:

```json
{
  "code": "de",
  "name": "Deutsch",
  "translations": {
    "Настройки": "Einstellungen",
    "Подключиться": "Verbinden"
  }
}
```

Ключи словаря — русские исходные строки интерфейса. Для непереведённых ключей используется русский текст; новый язык появится в настройках после перезапуска.

Ручная установка:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Linux для запуска GUI нужна графическая сессия. При первом подключении новый ключ SSH принимается автоматически и сохраняется в `known_hosts` в каталоге данных приложения; последующие подключения сверяют его и отклоняют несовпадение. В журнале подключения показывается fingerprint ключа. Это доверие при первом использовании (TOFU): для чувствительных серверов сверяйте fingerprint через независимый доверенный канал.

Профили серверов хранятся в `servers.json` в каталоге данных приложения. Пароли и passphrase не сохраняются. Для авторизации можно использовать SSH-агент или указать путь к ключу в профиле.

В SSH-сеансе встроенный терминал передаёт клавиши напрямую и поддерживает ANSI-цвета, изменение размера PTY и стандартные события мыши. Для вставки используйте `Ctrl+Shift+V`.

Можно держать открытыми несколько SSH-сеансов одновременно. Выберите сервер в списке, чтобы переключиться на его терминал; цветной индикатор рядом с именем показывает состояние подключения. При отключении очищается только его экран. Во время подключения над терминалом отображаются этапы SSH-аутентификации и ошибки соединения. Журнал можно показать или скрыть кнопкой на странице сервера.

На странице каждого сервера есть вкладки «Терминал» и «Файлы». Файловая вкладка позволяет просматривать удалённые каталоги, загружать и скачивать файлы, создавать каталоги, удалять объекты и просматривать файлы. Изображения, PDF, аудио и видео открываются во встроенном просмотрщике; другие документы — в системном приложении. Просмотр загружает временную копию размером до 512 МБ. Текстовые файлы также можно редактировать: двойной щелчок открывает редактор с подсветкой синтаксиса по расширению, `Ctrl+S` сохраняет изменения. Поддерживаются UTF-8-файлы размером до 2 МБ. Перед записью проверяется, не изменился ли файл на сервере после открытия.

В файловой вкладке есть переключатель `Root / sudo`. Он запускает SFTP-сервер через `sudo`; если пароль не требуется, режим включается сразу, иначе программа запрашивает пароль sudo для текущей операции. Пароль не сохраняется. Для режима нужны разрешение на sudo и установленный системный `sftp-server`.
