# VikhmanSSH

Автор: Dmitriy Vikhman

SSH арқылы серверлерді басқаруға және қашықтағы пәрмен жолында жұмыс істеуге арналған жұмыс үстелі қолданбасы.

## Іске қосу

Linux/macOS жүйесінде бастапқы жобаны іске қосу:

```bash
./run.sh
```

Windows жүйесінде `run.bat` файлын іске қосыңыз. Іске қосу скрипттері қажет болса виртуалды ортаны жасап, тәуелділіктерді орнатады.

## Дербес жинақ

Python мен кітапханалар бірге жинақталатын қолданбаны мақсатты операциялық жүйеде құрастырыңыз:

```bash
./build.sh
```

Windows жүйесінде `build.bat` файлын пайдаланыңыз. Дайын бума `dist/VikhmanSSH` ішінде пайда болады (macOS жүйесінде `VikhmanSSH.app` бумасы да жасалады). Оны сол операциялық жүйесі бар басқа компьютерге Python немесе тәуелділіктерді орнатпай көшіруге болады. Әр платформаға арналған жинақ сол платформаның өзінде жасалуы керек: PyInstaller бір операциялық жүйеден екіншісіне кросс-жинақтамайды.

## Интерфейс тілі

Негізгі терезедегі «Баптаулар» бөлімін ашып, қазақ тілін немесе БҰҰ-ның алты ресми тілінің бірін таңдаңыз: араб, ағылшын, испан, қытай, орыс немесе француз тілі. Таңдалған тіл барлық терезелер мен модульдерге қолданылуы үшін бағдарлама қайта іске қосылады. Тіл таңдауы мен қолданба деректері пайдаланушының жүйелік каталогында сақталады: Windows жүйесінде `%APPDATA%\ServerManager`, macOS жүйесінде `~/Library/Application Support/ServerManager`, Linux жүйесінде `${XDG_CONFIG_HOME:-~/.config}/server-manager`.

Жаңа тіл қосу үшін `locales/` каталогында `en.json` үлгісімен JSON файлын жасаңыз:

```json
{
  "code": "de",
  "name": "Deutsch",
  "translations": {
    "Настройки": "Einstellungen",
    "Подключиться": "Verbinden"
  }
}
```

Сөздік кілттері — интерфейстегі орысша бастапқы жолдар. Аудармасы жоқ кілттер үшін орысша мәтін көрсетіледі; жаңа тіл қайта іске қосқаннан кейін баптаулар тізімінде пайда болады.

Қолмен орнату:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Linux жүйесінде графикалық интерфейсті іске қосу үшін графикалық сессия қажет. Алғашқы қосылымда белгісіз SSH кілті автоматты түрде қабылданып, қолданба деректерінің каталогындағы `known_hosts` файлына сақталады. Келесі қосылымдарда кілт қайта тексеріледі және сәйкессіздік анықталса, қосылым қабылданбайды. Қосылым журналында кілттің fingerprint мәні көрсетіледі. Бұл — алғаш қолданғанда сенім білдіру (TOFU) тәсілі: маңызды серверлердің fingerprint мәнін тәуелсіз сенімді арна арқылы тексеріңіз.

Сервер профильдері қолданба деректерінің каталогындағы `servers.json` файлында сақталады. Құпиясөздер мен passphrase сақталмайды. Аутентификация үшін SSH агентін пайдалануға немесе профильде кілт файлының жолын көрсетуге болады.

SSH сеансында кіріктірілген терминал пернетақта енгізуін тікелей жібереді және ANSI түстерін, PTY өлшемін өзгертуді, стандартты тінтуір оқиғаларын қолдайды. Мәтінді қою үшін `Ctrl+Shift+V` пернелерін пайдаланыңыз.

Бір уақытта бірнеше SSH сеансын ашуға болады. Тізімнен серверді таңдап, оның терминалына ауысыңыз; атаудың жанындағы түсті индикатор қосылым күйін көрсетеді. Қосылым ажыратылғанда тек соған тиесілі терминал экраны тазаланады. Қосылу барысында SSH аутентификация кезеңдері мен қате туралы хабарлар терминал үстіндегі журналда көрсетіледі. Журналды сервер бетінде көрсетуге немесе жасыруға болады.

Әр сервер бетінде «Терминал» және «Файлдар» қойындылары бар. Файлдар қойындысы қашықтағы каталогтарды қарауға, файлдарды жүктеуге және серверден алуға, каталог жасауға және нысандарды жоюға мүмкіндік береді. Суреттер, PDF, аудио және видео кіріктірілген қарау құралында ашылады; басқа құжаттар жүйелік қолданбада ашылады. Қарау үшін файлдың уақытша көшірмесі жүктеледі; өлшемі 512 МБ-тан аспауы керек. Мәтіндік файлдарды да өңдеуге болады: файлды екі рет шерткенде кеңейтіміне сай синтаксис бояуы бар редактор ашылады, ал `Ctrl+S` өзгертулерді сақтайды. Өлшемі 2 МБ-қа дейінгі UTF-8 файлдары қолдау табады. Сақтау алдында файлдың серверде өзгермегені тексеріледі.

Файлдар қойындысында `Root / sudo` ауыстырғышы бар. Ол SFTP серверін `sudo` арқылы іске қосады; құпиясөз талап етілмесе, режим бірден қосылады, ал қажет болса бағдарлама sudo құпиясөзін сұрайды. Құпиясөз сақталмайды. Бұл режим үшін пайдаланушыда sudo рұқсаты және серверде жүйелік `sftp-server` орнатылған болуы керек.
